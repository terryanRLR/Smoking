# 01. 프로젝트 기획서

> 원본: 노션 "데이터 분석 팀 과제 기획서" 페이지를 재정리한 문서입니다.

## 팀 과제 제목
생체 신호 기반 흡연 여부 비교 시각화 프로젝트

## 팀 구성
- 팀명: 88하조 (내일배움캠프 QA/QC 5기 · 8조)
- 팀장: 이지아
- 팀원: 박재경, 안영진, 유지수, 이근주

## 팀 과제 목표

**해결 질문**
프로젝트 기간 내에 건강검진 데이터를 활용하여 탐색적 데이터 분석(EDA)을 수행하고, 결측치·이상치 처리 및 파생변수 생성을 포함한 전처리를 진행한다. 이후 시각화를 통해 흡연자와 비흡연자 간 주요 건강 지표(혈압, 혈당, 콜레스테롤, BMI 등)의 분포 차이와 패턴을 비교·분석한다. 더 나아가 성별, 연령대, 비만도 등의 세부 집단별로 흡연 여부에 따른 차이가 어떻게 달라지는지를 확인한다. 최종적으로, 어떤 건강 변수들이 흡연 여부와 유의미한 연관성을 가지는지 해석하고, 이를 의료진 및 정책 담당자가 직관적으로 이해할 수 있는 시각화 리포트 형태로 도출하는 것을 목표로 한다.

**가설**
- 일반 상식: 흡연자는 비흡연자에 비해 건강 지표에서 전반적으로 불리한 분포를 보일 것이다.
  1. 흡연 여부와 허리둘레는 유의미한 연관이 있을 것이다
  2. 흡연은 BMI와 무관하게 헤모글로빈 수치를 증가시킬 것이다
  3. 흡연자는 비흡연자보다 혈압이 더 높게 나타날 것이다
  4. 흡연자는 비흡연자보다 간 효소 GTP가 더 높게 나타날 것이다
  5. 흡연자는 비흡연자보다 혈청이 더 높게 나타날 것이다
  6. 흡연의 영향은 고BMI 집단에서 더 크게 나타날 것이다 → (검증 결과 흡연-BMI 단순 연관은 낮음, 파생가설로 이어짐)
  7. (파생가설) 흡연과 고BMI가 결합할 때 다른 건강 데이터 변수에 악영향이 있을 것이다

**SMART 목표**
| 항목 | 내용 |
|---|---|
| 구체적(Specific) | 생체 신호 데이터로 흡연자·비흡연자 차이를 분석하고 주요 변수 패턴 차이를 시각화로 확인 |
| 측정 가능(Measurable) | 최소 2~3개 이상의 시각화, 3개 이상의 인사이트를 결과 보고서에 포함 |
| 달성 가능(Achievable) | Python, Pandas, Matplotlib/Seaborn으로 전처리·기초 시각화 수행 |
| 관련성(Related) | 흡연 여부에 따른 생체 신호 차이 분석으로 건강 상태·행동 패턴 연관성 이해 |
| 시간 기반(Time-bound) | 4/2 가설 설정 → 4/3~6 분석·시각화 → 4/7 발표자료 제작 → 4/8 촬영 |

## 데이터 활용 계획

- **데이터 출처**: 제공된 바이오 데이터 CSV 파일 (`train_dataset.csv`)
- **주요 변수**: smoking, age, height(cm), weight(kg), waist(cm), systolic, relaxation, fasting blood sugar, Cholesterol, triglyceride, hemoglobin, Gtp 등

**전처리 계획**
- `head()`, `info()`, `describe()`로 변수 유형·결측치 우선 점검
- 이상치(예: 9999 등 비정상 값)는 결측치로 변환하여 분석 왜곡 완화
- 결측치는 평균값 또는 적절한 기준으로 대체
- 문자열 변수는 정수형으로 변환, 필요 시 파생변수 생성
- `height(cm)`, `weight(kg)`, `waist(cm)`으로 비만도(BMI) 지표 생성
- `smoking`, `age` 기준 그룹화·집계로 시각화·해석 가능한 형태로 재구성

**시각화 계획**
| 유형 | 용도 |
|---|---|
| 막대그래프 | 흡연 여부에 따른 연령 그룹별 건강 지표 비교 |
| 파이차트 | 흡연 여부별 주요 건강 지표 확인 |
| 선그래프 | 흡연 여부에 따른 연령 그룹별 건강 지표 추세 |
| 박스플롯 | 흡연 여부에 따른 연령 그룹별 분포·편차 확인 |
| 바이올린플롯 | 흡연 여부별 건강 지표 분포 밀도 비교 |
| 히트맵 | 주요 수치형 변수 간 상관관계 확인 |

## 예상 결과물 및 기대 효과

**최종 결과물 구성**
- 생체 신호 기반 흡연 상태 예측의 목적 및 배경
- 흡연 예측 데이터셋 정제 및 맞춤형 변수 가공
- 흡연자 vs 비흡연자 그룹 간 핵심 건강 지표 비교 (시각화)
- 머신러닝 흡연 예측 관련 결과 및 핵심 판단 기준
- 흡연 예측 분석의 한계점과 현실에서의 활용 방안

**기대 효과**
- 생체 데이터만으로 생활 습관(흡연 여부)을 예측함으로써 개인 맞춤형 건강 관리 가이드의 가능성 확인
- 도출된 인사이트를 향후 금연 캠페인·건강검진 지원 정책 설계의 기초 자료로 활용
