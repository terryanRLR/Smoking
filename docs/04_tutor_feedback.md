# 04. 튜터 피드백 및 팀 회고

## 서면 피드백

### 💬 메인 튜터 피드백 — 임영재 튜터

**1. 데이터 EDA 및 전처리**
- 데이터 전처리 시 의료적으로 유의미한 값(이상치가 아닌 질병 수치)들을 제거할 위험이 있어, IQR 방식 채택 시 전처리 결과와 원본 데이터를 비교해 왜곡을 방지해야 함
- 새로운 전처리 방식을 고안해보는 것을 권장

**2. 결과 해석 및 보고**
- 고BMI와 흡연 변수가 결합했을 때, 구체적으로 어떤 건강 데이터에서 가설과 부합하는 유의미한 결과가 나오는지 세부적으로 정리 필요

**3. 종합 피드백**
- 발표 흐름이 매우 깔끔함. 가설 설정을 완벽하게 하고 큰 틀에서 세부적으로 깊게 분석을 진행함

### 💬 서브 튜터 피드백 — 신재춘 튜터

**1. 데이터 EDA 및 전처리**
- 상관계수의 유의미한 범위를 미리 설정하여 분석의 객관성을 확보하려는 시도가 훌륭함 (`|r|≥0.2/0.3/0.4` 기준 — `docs/02_analysis_pipeline.md`의 point-biserial 상관 분석 참고)

**2. 결과 해석 및 보고**
- 60대 이후 혈압 역전 현상에 대해 연령 가중치라는 대안적 해석을 제시하고, 고BMI 집단과의 복합 작용을 심층 분석하여 설득력을 높인 점이 훌륭함

**3. 종합 피드백**
- 가설 설정부터 데이터 전처리, 상관관계 분석, 최종 결론 도출까지의 흐름이 체계적이며 시각화 자료의 가독성이 뛰어남

## 팀 회고 (KPT)

> KPT: Keep(잘했던 점) · Problem(아쉬웠던 점) · Try(다음에 시도할 것)

### Keep

- **이지아**: 어려운 과제였음에도 팀원 간 활발한 의사소통으로 과제 의도에 부합하는 결과물을 수행
- **박재경**: 서로의 의견을 공유하며 방향성을 제대로 잡아 나아갈 수 있었음
- **안영진**: 활발한 의견 교환과 업무 분담으로 협업, 가설 검증 과정에서 데이터 가공·분석·시각화 역량을 기름
- **유지수**: 분석 전 과정을 실시간으로 공유하며 더 깊게 분석·문제 해결. 다양한 시각화로 가설을 입증
- **이근주**: 의견을 적극적으로 공유·반영하며 발전. 어려운 상황 속에서도 꾸준히 자료 조사를 이어가 완성도 높은 결과물 도출
- **팀 전체**: 업무 분담 협업, 적극적인 소통

### Problem

- **이지아**: 다변수 바이오데이터 전처리 학습 필요, 코딩 숙련도 부족으로 시각화 구현에 시간 소요
- **박재경**: 유의미한 가설 설정·검증 방법에 대한 추가 학습 필요
- **안영진 / 유지수 / 이근주**: 데이터셋에 성별·고연령 데이터가 부족해 양질의 분석에 제약
- **유지수**: 다양한 전처리 방법을 알지 못해 아쉬움. 전 과정을 함께 하다 보니 역할 분배가 크게 의미 없어짐
- **팀 차원**: 성별·고연령 데이터 누락으로 인한 분석 제약, 시간 부족

> 이 회고에서 언급된 "역할 분배가 크게 의미 없어짐"과 "전 과정을 함께 함"은 `docs/03_issues_and_troubleshooting.md` Issue #3(team_final 내부 코드 중복)의 실제 원인과 정확히 일치합니다 — 여러 팀원이 같은 단계를 독립적으로 병행 작업했기 때문에 통합 시 네이밍과 전처리 기준이 갈라진 것으로 보입니다.

### Try

- 이상치 전처리 방법 추가 학습
- 전처리 과정을 결과 보고서에 더 비중 있게, 자세하게 작성
- 다양한 데이터 분석 기법 시도
